# Financial Performance Analysis by Country

## Objective
Analyze revenue, cost, and marketing efficiency across different countries.

## Tools
- SQL
- Excel

## Process
- Data extraction and transformation using SQL (joins, aggregations, null handling)
- KPI calculation: revenue, cost, gross profit, margin %, ROI %
- Final analysis and visualization in Excel

## Key Metrics
- Revenue
- Cost
- Gross Profit
- Margin %
- ROI %

## Key Insights
- The United States shows significantly higher ROI compared to other regions
- Marketing investment is less efficient in some countries
- Stable margins suggest consistent operational performance

## Business Impact
- Opportunity to optimize marketing budget allocation
- Potential to standardize operations globally
